# Buildkite Pipelines

Manage your Buildkite pipelines, builds, jobs, and agents directly from Visual Studio Code — without switching to the Buildkite web interface.

📖 **[Full documentation](https://buildkite.com/docs/platform/vscode-extension)**

## Features

- **Pipelines panel** — browse pipelines and recent builds, trigger rebuilds, cancel builds, unblock jobs, view annotations, and download artifacts
- **Agents panel** — view agent status and pause, resume, stop, or force-stop agents
- **Job logs** — view job log output inside VS Code with ANSI color support
- **Status bar** — see the build status for your current workspace's pipeline at a glance
- **Pipeline YAML validation** — real-time validation, autocomplete, and hover documentation for Buildkite pipeline files
- **Build notifications** — get notified when builds pass or fail

## Requirements

Visual Studio Code 1.60 or later.

## Getting Started

1. Install the extension from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=buildkite.buildkite-vscode)
2. Open the Command Palette (`Cmd+Shift+P` on Mac, `Ctrl+Shift+P` on Windows/Linux)
3. Run **Buildkite: Sign In** to authenticate via OAuth

See the [documentation](https://buildkite.com/docs/platform/vscode-extension) for full details on authentication, pipeline management, agent controls, and more.
